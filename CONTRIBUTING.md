# Contributing

Thanks for helping improve Open Utility Hub.

1. Fork the repository and create a branch.
2. Keep tools dependency-free unless a dependency is justified.
3. Make interfaces keyboard accessible and mobile responsive.
4. Validate inputs and handle invalid values clearly.
5. Add or update documentation and tests for calculations.
6. Open a pull request describing the change and how you tested it.

Do not add trackers, collect personal data, or include secrets/API keys.
